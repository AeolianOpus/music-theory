# SoundFont Files

Place your `.sf2` SoundFont file in this directory.

## Recommended SoundFonts (free, high quality)

### Option 1: MuseScore General (best overall)
- ~200MB, excellent instrument coverage
- Download: https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General.sf2

### Option 2: FluidR3 GM
- ~140MB, classic GM SoundFont
- Download: https://member.keymusician.com/Member/FluidR3_GM/FluidR3_GM.sf2

### Option 3: Timbres of Heaven
- ~380MB, studio-quality samples
- Search "Timbres of Heaven GM SoundFont" for current download links

## After downloading

1. Place the `.sf2` file in this `soundfonts/` directory
2. The app will auto-detect it on startup
3. If you have multiple `.sf2` files, you can select which one to use in Settings

## Note
SoundFont files are not included in the repo due to their size.
